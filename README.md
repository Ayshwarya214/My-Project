# VibeLens

VibeLens is a responsive visual discovery web application designed to let users search, filter, and explore high-quality photography and design inspiration seamlessly.

## Design Decisions
1. **Sticky Header:** Pinned the header to the top of the viewport using `position: sticky` so that the search bar and quick-pick filters remain constantly accessible while scrolling through image grids.
2. **Category Suggestion Chips:** Implemented interactive suggestion chips directly beneath the search input to allow users to instantly search popular themes like Nature or Architecture with a single click.
